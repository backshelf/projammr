Projammr is open source under the AGPL-3.0, and its code lives in one repository on
[GitHub](https://github.com/backshelf/projammr): the web app, the API, dit (the macOS menu bar app and Rust crates),
this site, and the packages they share. This section takes you from a fresh clone to a pull request that is ready to
merge.

<Aside type="note" title="Read this first">
  Projammr is heavily AI-assisted: AI coding agents write most of the code,
  tests and documentation, and one person directs the work and reviews it. [How
  AI is used](/ai/) says exactly what that means, including what review does and
  does not cover. If AI-written code is a dealbreaker for you, that page will
  tell you before you put any time in.
</Aside>

## The shape of a contribution

1. Clone the repository and get the apps running on your machine.
2. Make the change on a branch of its own, following the project's conventions, with tests for what it does.
3. Run the same checks CI runs until they are clean.
4. Open a pull request against `master`. The maintainer reviews it and merges it.
